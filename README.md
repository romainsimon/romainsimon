# Hey, I'm Romain Simon

> I'm just the human in the loop.

I'm a French solo founder who has been building things on the web since 1999. Today, I run a portfolio of software, AI tools, and experiments under [Yuki Capital](https://yukicapital.com).

An AI CEO helps manage day-to-day operations across the portfolio. I focus on product direction, strategy, taste, and deciding what should exist next.

## How I work

AI agents handle a large part of implementation, research, operations, outreach, and reporting. I remain responsible for priorities, product judgment, quality, and the rules they operate within.

My default web stack is **Nuxt, TypeScript, MongoDB, and Tailwind**, usually deployed on Hetzner with Coolify. I use Python when it is the simplest tool for the job.

I like boring, productive technology and ambitious products.
